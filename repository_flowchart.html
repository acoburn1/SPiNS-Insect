Quick Pipeline View

1) Entry

lab_tests/program.py parses CLI and dispatches pipeline stages.

2) Config

Parser.py + configs/utils.py resolve YAML config files into one RunConfig.

3) Preparation

Build train tensors, probe tensors/index, refs, and hyperparameter sweep ranges.

4) Train

Train model replicas for each (HLS, LR) pair and capture probe activations every epoch.

5) Store

Persist losses/activations in Zarr under run-specific suffix directories.

6) Evaluate

Run required evaluators, save .npz artifacts + stats + optional significance masks.

7) Output

Generate plots from analysis artifacts, optionally export tabular stats and metadata.

How to Run (CLI examples)

Basic stage execution

cd lab_tests
python program.py --train
python program.py --evaluate
python program.py --graph

Run all stages in sequence

cd lab_tests
python program.py --all
# optional progress display
python program.py --all --visual

Override config sets

python program.py --all \
  --data-config default \
  --model-config hls20 \
  --output-config default \
  --probe-config default \
  --directory-config default

Generate tabular exports

python program.py --tabular
# typically after --evaluate

Configuration System

  • configs/utils.py resolves each --*-config argument to a concrete YAML file path.
  • Unnamed config values default to configs/<type>/default.yaml.
  • RunConfig.__init__ loads data, model, output, probe, directory configs and computes sweep ranges.
  • get_stub(args) builds run directory naming stubs from selected config names.

Data + Probe Preparation

Training CSV parsing

  • Expected columns: input_0..input_(2F-1), output_0..output_(2F-1), type.
  • Only rows with type == train are used for model fitting.
  • Parsed arrays are validated against num_total_trials.

Probe generation workflow

  • Probe data is rebuilt each run from source datasets (avoids stale probe artifacts).
  • Sources can include exemplar, ratio, missing-feature, and onehot datasets.
  • Outputs: Data/Probes/<probe_name>.parquet and .index.json + runtime tensor.

Model + Training Loop

# effective loop order in RunConfig.train()
for HLS in hidden_layer_range:
  for LR in learning_rate_range:
    for model_i in range(num_models):
      model = StandardModel(...)
      result = model.train_eval(dataloader, X_probe)
  • Architecture is a shallow encoder-decoder: 2F → H → 2F with ReLU in the hidden layer.
  • Loss is BCEWithLogitsLoss; optimizer is Adam or SGD based on config.
  • train_eval captures probe hidden/output at initialization and after every epoch.

Activation Storage (Zarr schema)

# datasets written by DriverUtils/Zarr.py
loss   : (M, E)
hidden : (M, E, P, H)
output : (M, E, P, O)
  • Stored under run directories with pair-specific suffixes _hls{...}_lr{...}.
  • Zarr format supports efficient slicing for evaluator passes.

Evaluation + Statistics

  • Output/schema/dependencies.py maps output config keys to required evaluator classes and output classes.
  • Evaluators save raw model-level arrays, then Statistics/StatHelper.py computes aggregate summaries.
  • Saved analysis files generally include raw, mean, std, se, ci_lo, ci_hi, n.
  • Significance epoch masks are optional and written as sige.npz / wb-sige.npz.

Output Rendering + Grouping

  • Each output module reads analysis artifacts and emits OutputSpec objects.
  • PlotOutput.py renders specs to files in Output/....
  • Hyperparameter-dependent outputs run once per analysis root; per-pair outputs run for every HLS/LR directory.
  • DriverUtils/Organize.py can regroup files by graph type for easier comparison across pairs.

Tabular Export

  • DriverUtils/TabularExport.py creates CSV outputs for sig-mode and range-mode analyses.
  • Also exports mask tables from significance files.
  • Consumes AnalysisData outputs; it does not retrain models.

Metadata + Reproducibility

  • RunMetadata.write_stage_metadata logs stage status, timestamps, git branch/commit, and details.
  • Writes both stage history files under RunMetadata/<stage>/ and per-stage metadata.json.
  • Primary stage keys: activation_data, analysis_data, output.

Safe Change Guide (where to edit what)

Add a new evaluator

  • Implement evaluator in lab_tests/Eval/ using Eval/Protocol.py.
  • Register mapping in Output/schema/dependencies.py.
  • Enable via configs/output/*.yaml (present: true).

Add a new plot/output

  • Implement output class in lab_tests/Output/ using Output/Protocol.py.
  • Build OutputSpec objects compatible with PlotOutput.py.
  • Wire dependency and config presence similarly.

Change model behavior

  • Model architecture: Model/NeuralNetwork.py.
  • Training behavior: Model/StandardModel.py and RunConfig.train().
  • Re-run training + evaluate + graph to validate artifact compatibility.

Change probe/data behavior

  • CSV and source parsing in DataHelper/utils.py.
  • Probe rebuild/index logic in DataHelper/Probe.py.
  • Confirm downstream evaluators still read expected shapes/labels.
