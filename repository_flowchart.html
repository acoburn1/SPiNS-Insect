Quick Pipeline View

1. Entry

lab_tests/program.py
parses CLI and calls stage functions.

2. Config

DriverUtils/Parser.py, configs/utils.py
resolve YAML + initialize RunConfig.

3. Preparation

Build training tensors, probe parquet/tensor/index, reference matrices, model hyperparameter ranges.

4. Train

StandardModel.train_eval
train all model replicas; capture epoch-wise probe activations.

5. Store

DriverUtils/Zarr.py
write loss, hidden, output datasets.

6. Evaluate

Eval/* via Output/schema/dependencies.py → save AnalysisData/*.npz.

7. Output

Output/*.py + PlotOutput.py render figures; optional tabular export + metadata.

Start Here (for first-time contributors)

Read these in order:

1. lab_tests/program.py 2. DriverUtils/RunConfig.py 3. configs/output/default.yaml 4. Output/schema/dependencies.py 5. Eval/Protocol.py 6. Output/Protocol.py 7. Output/schema/OutputSpec.py

Repository Map (what lives where)

  • lab_tests/program.py: process entrypoint.
  • lab_tests/DriverUtils/
    • RunConfig.py: core orchestration for train/evaluate/graph/tabular.
    • Parser.py: CLI flags.
    • Zarr.py: activation I/O.
    • RunMetadata.py: stage metadata records.
    • Organize.py: output regrouping by graph name.
    • TabularExport.py: CSV/regression table exports.
  • lab_tests/Model/: NeuralNetwork.py, StandardModel.py.
  • lab_tests/DataHelper/: training CSV readers + probe builders + dataloaders.
  • lab_tests/Eval/: evaluator implementations.
  • lab_tests/Output/ and lab_tests/Output/schema/: output generators + rendering spec + dependency mapping.
  • lab_tests/Statistics/StatHelper.py: stats over models.
  • lab_tests/configs/: data/, model/, probe/, output/, directory/ YAMLs.
  • lab_tests/data/ + lab_tests/Data/: training/probe sources and generated probe files.

Configuration System

  • configs/utils.py resolves each --*-config argument to a YAML path; bare names map to configs/<type>/<name>.yaml.
  • get_stub(args) creates result path suffix from selected config names (except output/directory configs).
  • RunConfig.__init__ loads all config families and computes ranges for hidden-layer size and learning rate.
  • Guardrail: asserts special dataloader usage consistency based on trial ratios.

Data + Probe Preparation

Training data

  • csv_training_data_to_numpy reads row fields input_i/output_i and keeps rows where type == train.
  • Default loader is full-batch TensorDataset DataLoader; alternative is SpecialDataLoader.
  • Training trial count is validated against num_total_trials.

Probe building

  • DataHelper/Probe.py always rebuilds probe data from source CSVs/parquet generators.
  • Supports mixed sources: exemplar, ratio, missing-feature, onehot.
  • Writes lab_tests/Data/Probes/<cfg>.parquet + <cfg>.index.json.
  • Returns probe tensor + metadata dataframe + lookup index.

Model + Training

  • NeuralNetwork: encoder Linear(2F,H)+ReLU, decoder Linear(H,2F).
  • StandardModel chooses Adam or SGD from model config and uses BCEWithLogitsLoss passed by RunConfig.
  • train_eval first captures epoch-0 probe hidden/output (before training), then loops through epochs and stores loss/hidden/output.
  • Outer loops in RunConfig.train(): hidden-layer sizes × learning rates × model replicas.

Activation Storage (Zarr)

  • build_zarr_from_results initializes and writes model results into arrays.
  • Stored tensors: loss[M,E], hidden[M,E,P,H], output[M,E,P,O].
  • Each hyperparameter pair is stored under suffix directories like ..._hls{HLS}_lr{LR}.

Evaluation + Statistics

  • Enabled outputs in output config determine required evaluators via Output/schema/dependencies.py.
  • Evaluator classes include Correlation, MatrixCorrelation, WithinVsBetweenCorrelation, K95, RatioTest, MFA, Loss.
  • For each evaluator result, stats_over_models computes mean/std/se/ci.
  • Saved files: AnalysisData/.../<EvaluatorName>.npz with raw + summary stats (+ optional metadata).
  • If configured, significant epoch masks are generated using Eval/SigE.py as sige.npz / wb-sige.npz.

Output Rendering + Grouping

  • Output generators in Output/*.py convert analysis files into OutputSpec objects.
  • Output/schema/PlotOutput.py renders and saves plots.
  • RunConfig.generate_output() handles hyperparameter-dependent and per-pair outputs separately.
  • DriverUtils/Organize.py optionally groups matching plot names across pair directories.

Tabular Export

  • --tabular triggers RunConfig.generate_tabular_output().
  • DriverUtils/TabularExport.py exports sig-mode and range-mode CSV tables plus significance masks.
  • Tables are generated from existing analysis artifacts, not from retraining.

Metadata + Reproducibility

  • RunMetadata.write_stage_metadata() writes run records for activation_data, analysis_data, and output stages.
  • Each record contains timestamps, status, git branch/commit, stage directory, and stage details.
  • Metadata is written both to stage-history folders and stage-local metadata.json.

How to Make Changes Safely

Add a new evaluator

  • Implement class in lab_tests/Eval/ following Eval/Protocol.py.
  • Register evaluator dependency in Output/schema/dependencies.py.
  • Enable corresponding output entry in configs/output/*.yaml.

Add a new output plot

  • Implement output class in lab_tests/Output/ following Output/Protocol.py.
  • Generate OutputSpec objects compatible with Output/schema/PlotOutput.py.
  • Wire it in dependencies.py and mark present: true in output config.

Change model/data behavior

  • Model architecture/training loop: Model/NeuralNetwork.py, Model/StandardModel.py.
  • Data parsing/probe behavior: DataHelper/utils.py, DataHelper/Probe.py.
  • Re-run pipeline stages and validate artifacts in ActivationData/AnalysisData/Output.
