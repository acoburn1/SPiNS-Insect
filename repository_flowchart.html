SPiNS-Insect: Repository + Program Flowchart

Generated map of folder responsibilities, key files, and end-to-end execution flow from CLI invocation through plots and metadata artifacts.

1) End-to-end execution flow

2) Repository directory map + what each folder contains

Root

  • README.md: project overview and run commands.
  • requirements.txt: Python dependencies.
  • SPiNS_Insect.sln / lab_tests/SPiNS_Insect.pyproj: IDE project files.

lab_tests/

  • program.py: top-level executable entrypoint.
  • configs/: YAML config sets for data/model/probe/output/directories.
  • Data/ and data/: source datasets/probe assets/reference matrices.

lab_tests/DriverUtils

  • RunConfig.py: orchestration for train/eval/graph/tabular phases.
  • Parser.py: CLI flags.
  • Zarr.py: activation storage/load helpers.
  • RunMetadata.py: stage metadata logs.
  • Organize.py: output grouping.
  • TabularExport.py: regression table export.
  • Visual.py: progress rendering.

lab_tests/Model

  • NeuralNetwork.py: encoder/decoder network definition.
  • StandardModel.py: train loop + probe evaluation per epoch.
  • Parameters.py: model parameter utility module.

lab_tests/DataHelper

  • CSV/parquet conversion and dataloader utilities.
  • Probe.py: probe tensor build + metadata index generation.
  • SpecialDataLoader.py: alternate batching strategy.

lab_tests/Eval

  • Evaluator modules: correlation, matrix correlation, PCA/K95, ratio tests, MFA.
  • SigE.py: significant-epoch detection helpers.
  • Protocol.py: evaluator interface.

lab_tests/Output

  • Output generators that transform analysis artifacts to plot specifications.
  • schema/OutputSpec.py: plotting contract data model.
  • schema/PlotOutput.py: matplotlib rendering pipeline.
  • schema/dependencies.py: mapping from output config to evaluators/outputs.

lab_tests/Statistics

  • StatHelper.py: model-wise aggregate stats (mean/std/SE/CI).
