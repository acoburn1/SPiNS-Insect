SPiNS-Insect: Pipeline + Repository Flow (single visual map)

Centralized left-to-right main execution path, with structured sub-boxes and side branches for less-critical but important context.

Stage 1
Entry / CLI

Key file

  • lab_tests/program.py

Triggers

  • --train, --evaluate, --graph, --all
  • --tabular and optional --visual
Stage 2
Configuration Resolution

Config plumbing

  • DriverUtils/Parser.py
  • configs/utils.py resolves YAML paths
  • loads data/model/output/probe/directory configs

RunConfig setup

  • computes HLS/LR ranges, epochs, model count
  • creates output roots and dependency plan
  • saves result_dir/config.json
Stage 3
Model/Data/Probe Preparation

Training data prep

  • DataHelper/utils.py CSV → numpy
  • get_dataloader(...) or SpecialDataLoader

Probe prep

  • DataHelper/Probe.py rebuilds probe parquet
  • sources: exemplar, ratio, missing_feature, onehot
  • outputs tensor + metadata + index JSON

Model setup

  • Model/NeuralNetwork.py: 2F→H→2F
  • Model/StandardModel.py: Adam/SGD + BCEWithLogitsLoss
  • initial probe pass captured at epoch 0
Stage 4
Training Loop

Loop hierarchy

  • for each hidden-layer size × learning rate
  • for each model replica
  • for each epoch: forward → loss → backward → optimizer step

Captured each epoch

  • loss scalar
  • probe hidden activations
  • probe output activations (sigmoid)
Stage 5
Activation Persistence

Zarr writer

  • DriverUtils/Zarr.py
  • writes loss[M,E], hidden[M,E,P,H], output[M,E,P,O]
  • to ActivationData/.../activations.zarr
Stage 6
Evaluation / Analysis

Evaluator selection

  • driven by Output/schema/dependencies.py
  • Correlation, MatrixCorrelation, WB Correlation
  • K95 (PCA), RatioTest, MFA, Loss

Saved artifacts

  • AnalysisData/*.npz with raw + stats
  • Statistics/StatHelper.py: mean/std/se/CI
  • Eval/SigE.py: sige.npz, wb-sige.npz
Stage 7
Output Generation

Plot pipeline

  • Output/*.py generates OutputSpec structures
  • Output/schema/PlotOutput.py renders figures
  • DriverUtils/Organize.py groups outputs by name

Optional offshoot

  • DriverUtils/TabularExport.py builds regression tables

Repository structure branch

  • lab_tests/DriverUtils: orchestration, metadata, zarr I/O
  • lab_tests/Model: network + training wrapper
  • lab_tests/DataHelper: data/probe conversion + loaders
  • lab_tests/Eval, lab_tests/Output, lab_tests/Statistics

Data assets branch

  • lab_tests/data/Training: train CSVs
  • lab_tests/data/ReferenceMatrices: modular/lattice refs
  • lab_tests/data/Exemplar, Ratio, MissingFeature for probe sources
  • lab_tests/Data/Probes: generated probe parquet/index outputs

Reproducibility branch

  • DriverUtils/RunMetadata.py logs stage status + timestamps
  • records git branch/commit and stage-specific details
  • applies to activation_data, analysis_data, output stages
